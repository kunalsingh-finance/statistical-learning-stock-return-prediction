# Synthetic workflow showcase

Generated with seed 42, 36 feature months, 80 synthetic stocks, five scikit-learn models and the default 50-tree settings. No observed market returns or public proxy rows are used. `run_summary.json` records validation-only selection, forecast horizons, split ranges and runtime versions.

Regenerate using the command in the main README, then run `python scripts/verify_outputs.py --output-dir sample_outputs`. Predictions and diagnostics demonstrate pipeline controls; they are not evidence of investment skill. The original same-month proxy/test-selected performance claims are superseded.
